# Horizon Rooms — демосервис поиска отелей

**Целевая система — Ubuntu Server 26.04 LTS.** Проект доступен в историческом репозитории `respectr38-wq/forma-web`.

Адаптивный статический сайт: главная страница, каталог отелей, направления и помощь. Реализованы фильтры по городу, типу, бюджету и категории, сортировка, локальное избранное, проверка дат и выбор количества гостей.

**Важно:** каталог содержит вымышленные отели и условные цены. Это демонстрационный интерфейс, а не действующая система бронирования. Он не проверяет свободные номера, не принимает деньги и не передаёт поисковые запросы в серверную базу. Фотографии — иллюстрации Unsplash, не снимки представленных объектов.

## Установка на Ubuntu Server 26.04

Для нового VPS с настроенной DNS A-записью на публичный IPv4:

```bash
apt update && apt install -y curl
curl -fsSL https://raw.githubusercontent.com/respectr38-wq/forma-web/main/bootstrap.sh -o /tmp/horizon-bootstrap.sh && bash /tmp/horizon-bootstrap.sh respectr38-wq/forma-web
```

Если входите не как root, используйте `sudo bash /tmp/horizon-bootstrap.sh respectr38-wq/forma-web`.

Во время установки укажите домен и email для Let's Encrypt. Порт TCP/80 должен быть доступен для выпуска и продления сертификата; публичный TCP/443 занимает Xray REALITY. Установщик выбирает свободный внутренний HTTPS-порт, обычно `8443`, настраивает Nginx и Certbot, проверяет HTTPS и включает автопродление. Для 3x-ui укажите `Target = 127.0.0.1:ВНУТРЕННИЙ_ПОРТ`, `SNI = домен`, `Xver = 0`. Сам Xray, VPN-подключения, ключи, SSH и панель 3x-ui автоматически не меняются.

**Установка не перезаписывает уже существующий сайт для того же домена.** Если на VPS ранее установлен FORMA WEB, сначала сделайте резервную копию и подготовьте миграцию. Обновление GitHub не обновляет сайт на VPS автоматически.

## Диагностика

```bash
sudo forma-web-check ВАШ-ДОМЕН
sudo nginx -t
sudo systemctl status nginx --no-pager
sudo certbot renew --cert-name ВАШ-ДОМЕН --dry-run
```

Внутренний порт Nginx не следует открывать наружу. Если HTTPS доступен через VPN, но не без него, проверьте доступность TCP/443 по сети: замена содержания сайта не решает проблемы фильтрации провайдером.
